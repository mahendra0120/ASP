# Criminal Behavioral Analysis Skill

## When to Activate
- User wants the model to analyse the crime scene images
- When you get autopsy report from Forensic Agent,

## Step-by-Step Process
1. **Send the Image or Images that Involve the Victim's Body to the Forensic Agent**:
        - First, send either the crime scene image and/or autopsy image of victim's body to the forensic agent.
        - While waiting for the autopsy report, move onto the following step.
2. **Load and Read the Reference**:
        - Load the file `references\REFERENCE.md`.
        - Read through the basic version.
        - Then, go through the advanced version to learn more depth about this skill.
3. **Create the Crime Scene Report**:
        - Analyze every single detail in images to find any irregularites that does not appear in real life scenarios and places like living room, cafe, park, etc....
        - Compare and adhere the findings to the file `references\REFERENCE.md` as stated.
4. **Read the Autopsy Report from the Forensic Agent**:
        - Wait for the forensic agent to send the autopsy report.
        - When received, read through the autopsy report.
        - Move onto the following step.
5. **Establish the Serial Murderer Profile**:
        - Combine both the Crime Scene Report and the Autopsy Report.
        - Result should be formatted in a way laid out in  `references\OUTPUT.md`.
